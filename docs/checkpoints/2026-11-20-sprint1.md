## Important implementation contracts

- `RigLibrary` is the source of rig presets. Nothing in code assumes the Hueme
  Loft fixture count, ids, room size, or protocols.
- `Rig.with_fixture`, `without_fixture`, `with_group`, `assign_to_group` return
  fully validated copies for runtime editing.
- `ShowStore.commit` is one transaction = one undo snapshot. History minimum 50.
- `Compositor.evaluate(t)` is deterministic and returns float32 RGB + per-fixture
  snap flags + active clip metadata.
- HAL is opt-in, iterates the rig, splits Hue snap/smooth frames, emits 4-channel
  DDP for `rgb_amber_1800k`, and exposes `output_frame_async`.
- `config/rig.json` is intentionally gone; `config/rigs/<id>.json` + active
  index is the new model.
