## Contracts locked

- Custom palettes are global user data, `config/palettes.json`.
- Built-in palettes cannot be overwritten or deleted; saving a built-in creates
  a copy.
- FX preview is a front-plane editor render, never a hardware path.
- Preview renders are serialized and cached; filter previews are 48×27.
- Clip auto-name = null name; track auto-name = explicit `name_auto` flag.
- Legacy tracks default to `name_auto=false` so opening an old show does not
  rewrite names.
- One icon set: MDI paths, filled, 12 px default, 14 px in context menus.

## Deliberate limits

- Filter parameters are static values; no filter keyframes yet.
- FX preview uses the synthetic deterministic envelope, not the attached
  AudioBlueprint.
- FX preview is a single mid-depth front plane; strongly volumetric effects
  read as a flat projection.
- No new particle presets or expression functions in this phase.
