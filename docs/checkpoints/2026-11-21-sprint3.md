## Contracts locked this sprint

- MCP tools are the same edit path as REST: `ShowStore.commit` only, one
  transaction per write call, shared invalidation bus.
- stdio MCP is a proxy to a running studio server; there is no second runtime.
- No MCP SDK dependency: initialize/tools only, JSON responses, no SSE stream.
- Blueprint cache is content-addressed; only 16-bit PCM WAV is accepted.
- Lint errors do not block commits; they are surfaced to the operator/agent.
- `Compositor.env_provider` switches to the blueprint only when attached;
  otherwise the synthetic envelope is byte-for-byte unchanged.

## Deliberate limits

- MCP has no SSE progress/listChanged/auth; add when a client needs it.
- Blueprint extraction is one WAV at a time; no ffmpeg/MA fetch yet.
- Blueprint envelope is beat-level (not per-hop); upgrade if effects need
  sub-beat detail.
- Timeline waveform is 1024 buckets; increase when zoomed editing needs it.
