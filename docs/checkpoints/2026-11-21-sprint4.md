## Contracts locked this sprint

- Matching is conservative; ambiguity is a no-match, never a guess.
- PLL trims rate for errors < 750 ms; larger errors snap. Positive offset
  delays the lights.
- Sync is opt-in. A disconnected source leaves manual transport untouched.
- HA commands are queued from paho's callback and applied only on the runtime
  tick.
- HA is opt-in; preview never needs a broker.
- The image defaults to the Studio server on 8090 and does not bake
  `gateway.json`, pairings, caches or logs.

## Deliberate limits

- Sync follows Sendspin metadata progress, not per-hop audio analysis.
- No automatic AudioBlueprint import from MA.
- HA exposes four control/status entities, not per-fixture lights.
- No MQTT TLS flags, no broker mDNS discovery, no HA WebSocket API.
- HAL output remains unwired to the Studio transport.
